# BusinessIntel

BusinessIntel is a .NET 8 business intelligence and lead generation platform currently under development.

## Current Features

- Google Maps automation using Microsoft Playwright
- Search-driven business discovery
- Automatic area expansion
- Infinite scrolling
- URL deduplication
- SQLite database
- Entity Framework Core
- Repository pattern
- Modular Clean Architecture
